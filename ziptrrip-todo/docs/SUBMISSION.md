# Submission Checklist

Before submitting:

1. Run backend tests:
   `cd backend && npm install && npm test`
2. Start backend:
   `npm run dev`
3. Start frontend in another terminal:
   `cd frontend && npm install && npm run dev`
4. Verify:
   - `/`
   - `/todo.html?id=1`
   - CRUD APIs
5. Import the Postman collection.
6. Create a Git repository and push the project.
7. Share the repository URL with Ziptrrip.

Suggested repository description:

> Full-stack TypeScript Todo MPA built for the Ziptrrip Tech assignment using React, Vite, Express and SQLite.
